## Objective and approved scope

AI01 canonical actor identity; AI02 opaque L3 profile reference; AI03 detached
immutable AI State; AI04 structural decision/context/action/result; AI05 optional
Actor AI module. Same functions for arbitrary canonical Entity kinds.
Six functions/seven types are listed in [API](../../API.md).
Creation starts with null target, explicit manual/ai controller and behaviorStateId.
Nonblank string identities preserve exact spelling/case. State validation requires
actor existence through canonical Entity lookup; target reference need not exist.
Result validation binds state/context/intent actor and decision IDs; manual cannot
propose, no_action reasons are controller-specific. No optimistic execution.

Phase D01: L2 owns immutable schema, L4 stores/commits. D02: FSM+priority design,
opaque behavior identity only here. D03: one controller per actor. D04: actual
execution feedback later; structural association only. D05: explicit deterministic
inputs, no hidden time/RNG/IDs. Historical project decisions remain intact.
