## 11. Deterministic replay and independent oracle protocol

Provide at least two **independently initialized** L4 sessions with fixed explicit definitions, Entity creation, initial resources/Life, sides, active policies, membership, random sequences, clock samples and resolved objective/world facts. Each session must invoke actual installed root functions from foundation to terminal; neither may copy snapshots/ledgers from the other.

3. **Negative control:** Change one explicit input (RNG draw or L3 completion priority or membership/turn order). Assert the expected literal **different** trace and make sure the old expected digest no longer fits. Never use the implementation under test as its own expected-output generator.
4. **Provider isolation:** No hidden `Date.now`, `Math.random`, environment time, `setTimeout`, mutable module-global counters or default IDs. If used anywhere by required module, fail and escalate. 5. **State isolation:** Freeze/detach result structures; provider/caller inputs remain independently owned and unaffected. No replay reusing old L4 ledger, closure token, temporary directory or global store across tests.
