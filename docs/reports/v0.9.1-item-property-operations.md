## Exact approved delta and behavior

Three functions are appended to the existing Item owner and root:
getItemInstanceProperty, setItemInstanceProperty, replaceItemInstanceProperties.
Three types are added: ItemPropertyReadResult, ItemPropertyOperationAdmission,
ItemPropertyOperationResult. Function signatures match the task. The original
seven functions/eight types retain byte-identical source and declaration prefixes.
ItemDefinition/ItemInstanceState/ItemPropertyValue/reference shapes stay unchanged.

Each operation calls canonical validateItemInstance, which first validates the
complete definition then the complete bound instance. Reads use Object.hasOwn on
the detached validated instance map. Supplied set values and replacement maps use
the existing copyValue/properties recursive guards. Admission uses the existing
closed own-data fields helper and an exact boolean check, after payload validation.
Accepted candidates are revalidated by validateItemInstance; rejected results are
fresh frozen closed records with candidate:null. No alternative validator exists.

Property keys preserve any exact string, unlike identity IDs. Set copies the old
map and defines the named own key safely, including __proto__. Replacement uses
only the supplied map; omitted instance keys disappear. No definition defaults,
normalization, arithmetic, provider, cache, event or persistence is introduced.

Literal installed examples (definition has shared:'definition-only', charge:999;
instance IDs are ' I道 '/' D道 ', properties charge:1,note:null):

```js
getItemInstanceProperty(def, before, 'note')
// {found:true,value:null}
getItemInstanceProperty(def, before, 'shared')
// {found:false}, no own value field
setItemInstanceProperty(def, before, 'charge', 2, {eligible:true})
// {status:'accepted',reason:'none',candidate:{
//   instanceId:' I道 ',definitionId:' D道 ',properties:{charge:2,note:null}}}
replaceItemInstanceProperties(def, before, {fresh:[true,0]}, {eligible:true})
// same IDs; properties exactly {fresh:[true,0]}
setItemInstanceProperty(def, before, 'charge', 4, {eligible:false})
// {status:'rejected',reason:'ineligible',candidate:null}
```

L2 owns structural transition candidates only. L3 decides allowed keys, value
meaning/ranges and numerical rules; L4 computes admission from authoritative facts,
rechecks freshness and commits. Eligible is not authority/ownership evidence.
Item has no Inventory quantity, Equipment, effects or durability policy.
