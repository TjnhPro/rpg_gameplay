## D. Architecture and self-review

One Combat owner, one structural schema/validation path. Closed own-data semantics
match existing records including null-prototype inputs. The private identifier
helper checks opaque strings only and does not duplicate Entity definition logic.
No imports are needed; no fake Entity, lookup, Kernel formula or dummy call.
Entity/Progression/Foundation production files and Core pin are unchanged.
Registry preserves notes and existing entries, adds only combat -> entity.
No global state, registry, queue, persistent session, engine, event/hook bindings,
Skill dependency or speculative target union. Reflection sees only frozen data.
Installed runner retains every existing oracle, and checks exact public inventory.
