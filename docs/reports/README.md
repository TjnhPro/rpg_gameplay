# Verification reports

Versioned phase reports in this directory are historical evidence for the commit
and harness that produced them. Their installed-consumer paths, source hashes,
mutation controls, test counts and eight-job CI requirements were superseded by
the approved MVP harness simplification; they are not current executable gates.

Current rules: [testing](../TESTING.md), [verification](../VERIFICATION.md),
[task execution](../TASK_EXECUTION.md). Current migration evidence and coverage:
[harness simplification](harness-simplification-mvp.md).
