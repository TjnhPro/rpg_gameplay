## B. Authorized contract delta

- EntityAttributePointState adds required readonly `pointKind: 'attribute'`.
- EntitySkillPointState adds required readonly `pointKind: 'skill'`.
- Public factory input remains the same closed three-field balances/cursor record.
  Factories choose kind internally; extra initial pointKind rejects.
- Every point-taking operation requires the exact own-data expected kind and
  closed state shape before grants/spending or valid-blocker evaluation. Missing,
  opposite, unknown, wrong-case, inherited/accessor kinds reject with TypeError;
  getters/coercion are not invoked. No fallback or silent conversion.
- Returned factory/reward/allocation/upgrade/blocked snapshots preserve kind,
  precise public return type and immutable detachment.

Exact snapshot consumers must add the kind. Untagged old snapshots reject; no
migration or normalization. pointKind is structural domain identity, not a trusted
security credential; callers can construct correctly shaped data deliberately.
Old immutable snapshots can still branch. No exactly-once/concurrency authority.
