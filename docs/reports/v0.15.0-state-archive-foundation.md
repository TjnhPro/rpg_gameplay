## Public contract frozen through v0.15.3

```ts
export type PortableValue = null | string | number | boolean |
  readonly PortableValue[] | {readonly [key: string]: PortableValue};
export interface GameplayStateRecord {
  readonly moduleId: string;
  readonly stateKind: string;
  readonly stateId: string;
  readonly schemaVersion: number;
  readonly payload: PortableValue;
}
export interface GameplayStateArchive {
  readonly formatVersion: number;
  readonly records: readonly GameplayStateRecord[];
}
export function validateGameplayStateRecord(record: GameplayStateRecord): GameplayStateRecord;
export function validateGameplayStateArchive(archive: GameplayStateArchive): GameplayStateArchive;
```

Both functions validate and return detached, deeply frozen data or throw TypeError.
The archive reuses the record validator. IDs retain their exact nonblank strings;
version labels are independent positive safe integers. Neither is interpreted as
an approved owner/schema. Empty archives are valid. Unknown envelope/record keys,
hidden/symbol/accessor properties, holes, extra array fields and nonplain objects
are rejected. Payload numbers must be finite and cannot be negative zero.
Own `__proto__` keys are copied as inert data. Shared acyclic input references
are independently copied; cycles fail. Caller getters are never evaluated.

## Limits and delivery

Validation is structural only: no domain validity, recognized version acceptance,
cross-system consistency, serialization API, rehydration, storage, save/load or
commit guarantee. Ordinary transparent proxies cannot universally be identified
in JavaScript; inspection traps that throw are normalized to TypeError. No claim
is made for arbitrary resource-exhausting or adversarial proxy code.

The existing PR workflow covers one Ubuntu/Node22 job at the exact PR head.
Windows evidence above is local; Windows/Node24 CI and broad L4 regressions are
NOT_RUN. ST06 onward is NOT_IMPLEMENTED. No merge, Ready transition, release tag,
publish or next milestone is authorized by this checkpoint report.

Delivery includes `git diff --check`, source/registry/API/test/catalog scope
review, commit/push and one Draft PR. Its delivery supplement identifies the exact
commit, observed CI result and remaining review status without moving that head
