### Implementation decisions recorded before source edits

- Separate typed EntityResourceState with exact entityId and frozen detached
  current numeric map. Fixed arbitrary nonblank exact resource IDs, including
  constructor/__proto__, set at initialization; empty map valid. No state carrier
  in v0.2.2 owns current resources; do not alter Entity/Collection/Attribute schemas.
- Caller supplies minimum/maximum/policy per operation; state stores current
  only. Entity identity creation reuses createEntity. Structural resource states
  validate/detach own finite numeric data, with no global membership association.
- Definition composes Kernel ResourceNormalizationInput without resource;
  initialization validates the entire map before normalizeResource per resource.
  Omitted current is omitted to Kernel, not filled in L2. Explicit normalization
  returns next state plus frozen authoritative Kernel normalization calculation.
- Transition composes ResourceTransitionInput without resource/current; validates
  finite ordered bounds, amount>=0, current>=minimum, operation and complete rule.
  calculateResourceTransition alone owns numerical/applied/reachedMinimum results.
  Above-max allow/reject and negative applied are preserved verbatim.
- Regeneration composes ResourceRegenerationInput without resource/current;
  eligible true validates normalized current, finite ordered bounds, rate/time>=0
  and integer precision0–100. False preserves Kernel early no-op: read only own
  eligibility and validated state/ID, never ignored bounds/rate/time/precision,
  including their accessors. Forward a minimal false input, no synthetic defaults.
- Regeneration reuses the transition result envelope because Kernel returns the
  same ResourceTransitionResult. Freeze detached scalar diagnostics; never
  reconstruct applied, initialized or reachedMinimum. TypeError for malformed
  active input; canonical Kernel errors propagate; no partial snapshot on failure.
- Stats-to-resource maximum mapping is explicit caller input; no listeners,
  mapping vocabulary, refill, ratio preservation, life state, events or scheduler.
- Planned files: Entity owner/root exports, new resource installed JS/TS consumer
  and existing installed harness inventory, version-only package/lock, verify
  final scope text, affected onboarding/API/architecture/Core/testing docs,
  active approved task and this report. Registry/Core/Foundation/old fixtures and
  prior reports unchanged.
- Verification: independent initialization80/50, decrease55/increase70,

  edge/failure/ownership/Stats integration; strict external0.2.3 installation,
