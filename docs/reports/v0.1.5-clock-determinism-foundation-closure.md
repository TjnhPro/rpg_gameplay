## B. Implementation

One independent owner `src/foundation/execution/index.ts`; no other production
owner changed. Required clock, optional RNG and IDs; methods and receivers are
captured once, providers are not invoked at creation, mutated, cloned or frozen.
Opaque frozen capabilities use private weak identity associations; reflection
reveals no callback/record and copied brands cannot grant access. Records contain
only captured callbacks, no global sequence, cache, scheduler or gameplay state.

GF14 returns finite nonnegative milliseconds exactly as supplied, including zero,
fractional values and backward time. GF15 RNG accepts finite [0,1); IDs accept
nonblank strings unchanged, including arbitrary format and repeated values.
Missing/invalid ports, forged contexts and invalid outputs throw TypeError.
One call per explicit request, no retries/restoration; provider-thrown values
propagate unchanged. Existing callback failure owners retain their semantics.
GF16 is conditional reproducibility, not a promise about arbitrary callback IO.
