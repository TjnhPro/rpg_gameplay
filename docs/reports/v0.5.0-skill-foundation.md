## Implementation and exact public surface

```ts
interface SkillDefinition { readonly skillId: string; }
interface SkillInstanceInitialState { readonly instanceId: string; }
interface SkillInstanceState {
  readonly instanceId: string;
  readonly skillId: string;
  readonly entityId: string;
}
function createSkillDefinition(definition: SkillDefinition): SkillDefinition;
function createSkillInstance(definition: SkillDefinition, entity: EntitySnapshot,
  initial: SkillInstanceInitialState): SkillInstanceState;
```

Canonical owner: src/modules/skill/index.ts. One private helper validates closed
single-own-data-property records/nonblank strings. No helper is exported. The
instance factory revalidates through createSkillDefinition and public createEntity,
captures caller instanceId and freezes only a new scalar result. Input records
are never frozen or mutated. No EntitySnapshot or rich definition object is retained.

All identities remain exact/case-sensitive; whitespace is checked only for
blankness, never normalized. Duplicate instanceId creation is intentionally valid
structural data; no registry/idempotency/global uniqueness guarantee exists.
Malformed definition/Entity/initial records throw TypeError without invoking
getters or producing partial state. Structural validity does not prove membership,
learning, rank, life status, ownership, availability, equip or activation.

Public additions: createSkillDefinition/createSkillInstance and SkillDefinition/
SkillInstanceInitialState/SkillInstanceState, root only. Current inventory:
67 runtime functions/98 exported types (prior65/95 retained). Exact runtime root
inventory, generated declarations and strict external type consumers are checked.
No deep paths, dependency package or existing signatures changed.
