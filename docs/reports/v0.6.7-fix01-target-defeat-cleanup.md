## 3. Root cause

Old explicit removal correctly uses lifecycle.observedAtMs (still1000).
Periodic completion advances its companion cursor but not lifecycle observation.
There was no dedicated terminal transition carrying actual death time and allowing
cancellation of same-time ticks after canonical Entity death.

## 4. Canonical owner analysis

Core owns numbers; Entity owns Resource/Life. Effect owns membership/lifetimes,
tick intents and companion payloads. L3 chooses cleanup policy. L4 binds actual
death time to Entity outcomes, stages complete candidates and owns authoritative
publication/freshness. None of those responsibilities move.

## 5. Fix design

`cleanupDefeatedTargetEffects(lifecycle, periodic, targetLife, request, context)`
validates aligned snapshots, same-Entity dead Life and explicit time, then creates
an empty canonical lifecycle at that time with lexical instance-ID removals.
It is an explicit function, not a listener, scheduler or automatic death policy.
Empty dead-target cleanup succeeds with no events and aligns observation time.

## 7. Target-death timestamp semantics
