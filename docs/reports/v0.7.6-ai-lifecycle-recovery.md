## 6. Life gate and precedence

Validate Actor AI against EntityCollection; Life is a closed own-data entityId/status
record exactly bound to actor. Dead precedes manual, both block before timing/action.
Alive AI returns allowed. Wrong/missing Life, nonmember actor, malformed state and
inherited/accessor/extra fields fail closed. Pending proposed action is rechecked
against current Life/controller at actual L4 dispatch, including death after proposal.

## 7. Target death and loss

Canonical target Life feeds existing perception and AI09/AI15 target selection.
Dead target is excluded, stale target lost, alternate reacquired only by accepted
selection policy. AI does not calculate Life from HP or alter target Life/resources.

## 8. Explicit reset

Respawn/session_reset requires nonblank L3 destination present in bound behavior
policy. Disengage requires null reset destination, preserves current behavior and
clears target; FSM performs later transition. Current behavior must exist in policy.
Validation runs before dead no-op. Dead returns rejected/actor_dead/state:null.
Alive returns applied metadata candidate. Caller must explicitly request and commit.

## 9. Ownership and revival

Actor/profile/controller preserved; manual metadata reset remains manual. Entity
resolveEntityDefeat/reviveEntity own Life transitions and resource requirements.
L4 fixture keeps activation separate: real revival does not auto-enable AI; explicit
reset/controller/timing/activation decisions remain caller-owned. AI never restores HP.

## 10. Disengage and Returning

L4 stages target-clearing candidate, uses existing target-absent leash/disengage FSM
rule, then rechecks Life/controller and AI/Life baseline before publishing. Death or
manual control between stages cancels publication. Missing rule preserves truthful
no-transition result. Returning does not mean World arrival; explicit caller World
signal is required before guarding. Position remains untouched by AI.

## 12. Regression, representability and zero

now below observedAtMs blocks time_regressed. Nonfinite result or positive interval
that cannot advance floating-point time blocks time_unrepresentable, never clamps.
Interval must be a nonnegative safe integer. Interval0 is due at same timestamp and

publishes one candidate and rejects second stale concurrent proposal. Canceled/manual
or stale AI/Life turn does not consume authoritative cursor. This reference protocol
is local fixture evidence, not distributed concurrency or an L2 dispatch lock.
