and Equipment prepare independent transitions with L4 coordination. C-D07=A: Loot
selects explicit creation inputs; it does not give Item a loot engine.

uniqueness, ownership, persistence, freshness/concurrency and authoritative commit.

All signatures/shapes follow the task and are implemented only in
src/modules/item/index.ts. Reference helpers require narrow references. Definition
fields are definitionId/categoryId/tagIds/rarityId/properties; instance fields are
instanceId/definitionId/properties. No quantity, owner, slot or location field.

Compiler adjustment: the literal recursive alias through Readonly<Record<...>>
produced TS2456 with pinned TypeScript 6.0.3. The recursive branch uses
`{readonly [key: string]: ItemPropertyValue}` instead. This is the same public
structural contract, proved by an exact type-equality assertion against the approved
Readonly<Record> expansion in the strict installed consumer. No additional public type.

IDs preserve exact nonblank strings. Nullable metadata is opaque, tags ordered
and exact-unique. Records require exactly own string data fields and plain/null
prototypes. Values recursively preserve finite numbers including -0, booleans,
strings, null, dense arrays and dictionaries. Dangerous keys are defined safely.
Accessors are never read; malformed values, cycles, unsupported prototypes,
symbol keys and sparse/extended arrays throw TypeError. Every public call returns
a fresh detached deep-frozen snapshot. Definition properties never merge into an
instance. No implicit ID/time/random provider, store, policy or numeric calculator.

## Risks and checkpoint boundary

Portable JavaScript has no reliable universal Proxy detector: descriptor/prototype
traps can execute caller code, and transparent proxies cannot generally be identified.
The implementation avoids normal property getters/get traps, rejects accessors and
failed inspection, and claims no sandbox for adversarial JavaScript. Caller resource
limits are still needed for extremely large/deep data; no arbitrary game schema,
max-depth policy or universal denial-of-service protection is claimed.

No snapshot proves global ID uniqueness, catalog membership, ownership, freshness,
policy eligibility, persistence or authoritative commit. Structural Item data does
not implement Inventory/Equipment/Loot/Reward or evaluate concrete gameplay profiles.
